# Kairo: Enterprise Clarity

You are an expert Product Designer, UX Designer, UI Designer, and Frontend Engineer.

We are building a real B2B SaaS product called **KAIRO**.

This is NOT a demo project, template, or college project.

The goal is to create a production-quality marketing website that looks like it belongs to a mature enterprise software company.

I am providing two references:

1. KAIRO Product Requirements Document (PRD)

2. Screenshots of the Jira website

Treat them differently.

=========================================

HOW TO USE THE REFERENCES

=========================================

The PRD is the source of truth for:

- Product understanding

- Features

- User roles

- Modules

- Workflows

- Website content

- Messaging

The Jira screenshots are ONLY for understanding:

- Layout

- Section order

- Visual hierarchy

- Spacing

- Typography

- Overall professionalism

- Component arrangement

- Modern SaaS design principles

DO NOT copy:

- Jira branding

- Jira colours

- Jira icons

- Jira illustrations

- Jira content

- Jira logo

- Jira graphics

Create a unique identity for KAIRO.

=========================================

HOW TO TREAT THE PRD

=========================================

The uploaded PRD contains the complete product specification.

However, DO NOT use the entire PRD while designing the marketing website.

Use the PRD ONLY to understand:

• What KAIRO is

• Who the product is built for

• The business problem it solves

• The overall vision of the product

• The major modules and features (only as website content)

• The product positioning

Ignore everything related to:

• Dashboard implementation

• Internal pages

• User workflows after login

• Database tables

• APIs

• Authentication flow

• Role permissions

• Backend logic

• Forms

• Reports

• Notifications

• Technical implementation details

Those parts will be implemented later when we build the actual platform.

At this stage, focus ONLY on building the public-facing marketing website.

The website should educate visitors about KAIRO, build trust, explain its value, and encourage them to sign up.

The website should NOT attempt to recreate the dashboard or internal application.

DELIVERABLE

Build a complete production-quality KAIRO marketing website using the PRD as the product reference and the Jira screenshots as UI/UX inspiration.
